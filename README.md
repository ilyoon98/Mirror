# MIRROR RUSH — 거울 방 레이저

거울로 가득한 방에 레이저를 설치하고, 반사를 읽어 EXIT로 빼내는 아케이드 퍼즐입니다.

**▶ 플레이: <https://mirror-rush.ilyoon362.workers.dev>**

## 어떤 게임인가

- 빈 타일을 눌러 레이저를 **설치**하고, 같은 자리를 한 번 더 누르면 **발사**합니다.
- 거울 `╱ ╲` 은 빔을 90° 꺾습니다. 초록 **EXIT**로 나가면 클리어.
- 출구가 **두 개**입니다. `EXIT`는 ×1, `EXIT ×2`는 배점 2배지만 경로가 더 짧습니다.
  매 판 `칸수 × 배수`를 비교해 어느 쪽을 노릴지 골라야 합니다.
- **소멸 타일**에 닿으면 빔이 흡수되어 실패합니다. **FLIP**(`G`)은 모든 거울을
  `╱ ↔ ╲` 로 뒤집습니다 — 횟수 제한 없이 몇 번이든 쓸 수 있습니다.
- 레벨 6부터 **프리즘** — 빔이 **좌 90°·우 90° 두 갈래**로 갈라집니다(직진은 없습니다).
  한 갈래만 `EXIT` 로 나가도 클리어이고, 죽은 갈래는 그 갈래만 무효입니다.
  **보드를 벗어난 갈래 수**가 배율입니다 — 2갈래 1.25배 · 3갈래 1.6배 · 4갈래 2배.
- 레벨 8부터 **단방향 거울** — 위·왼쪽에서 들어오면 통과, 아래·오른쪽에서 들어오면 반사합니다.
- 콤보 5마다 **FEVER** — 1×5 레인에서 출구가 좌우 중 한쪽에 열리고, 거울은 빔을 막습니다.
- 레벨 13부터 6×6, 25부터 7×7로 **방이 넓어집니다.**

### 시간 — 런 전체가 60초

판마다 초기화되는 제한시간이 아니라 **런 전체가 하나의 시간 풀**을 씁니다.

- **0이 되면 그 자리에서 끝**입니다. 라이프는 없습니다 —
  틀린 발사의 대가는 거기에 쓴 시간 그 자체입니다.
- 시간은 **판을 보고 있는 동안에만** 흐릅니다. 빔이 나는 동안에는 멈춥니다.
- **피버 구간에서는 줄지 않습니다.**
- **PERFECT 한 발마다 2초 회복** — 단, 60초를 넘기지는 않습니다.

## 순위

기본은 **자유 플레이**입니다. 런마다 새 판을 받아 죽을 때까지 이어 가고,
점수는 하나의 전체 순위표에 모입니다.

- 판이 매번 달라도 비교가 성립합니다. 한 런은 레벨 1부터 **같은 생성기·같은 난이도 곡선**을
  순서대로 밟으므로 판 하나하나의 운은 런 전체에서 평균으로 씻겨 나갑니다.
  엔드리스 아케이드가 하나의 순위표를 쓰는 것과 같은 이유입니다.
- **전체 / 최근 7일** 로 기간을 골라 볼 수 있습니다.
- **오늘의 판**은 보조 탭입니다. 단 하나의 판을 푸는 형식이라 시드를 UTC 날짜로 고정해
  전 세계가 같은 문제를 풉니다.
- 게임이 끝나면 자동으로 등재되고, 우측 상단 **순위** 버튼에서 언제든 볼 수 있습니다.
- **랭킹 점수는 시간 보너스를 뺀 값**입니다. 클라이언트가 보고한 시각은 서버가 검증할 수 없어
  비교 기준에서 제외합니다.

### 자유 플레이 시드는 서버가 발급합니다

스스로 고른 시드를 인정하면 유리한 판만 골라 담을 수 있습니다.
그래서 판을 그리기 전에 서버 응답을 기다리고, **같은 기기에 열려 있는 런이 있으면
같은 판을 그대로 돌려줍니다**(10분).

게임 중간에 이탈하고 다시 시작하면 같은 판이 나오는 것은 이 때문입니다.
정상적으로 게임 오버까지 가면 자동 제출되고 새 판을 받습니다.

재사용은 **기기 단위**입니다. IP 단위로 묶었다가 같은 네트워크의 두 사람이 한 판을
공유해 뒤에 끝낸 쪽이 등재에 실패하는 문제가 있었습니다(v1.4 에서 수정).

### 점수는 어떻게 믿을 수 있나

서버는 **점수를 받지 않습니다.** 입력 로그만 받아 [`public/core.js`](public/core.js)로
그대로 재생해 스스로 채점합니다. 게임과 서버가 **같은 파일**을 쓰므로 규칙이 어긋날 수 없습니다.

- 그 시드에서 불가능한 수(거울 칸 발사, 범위 밖, 잘못된 방향)는 거부합니다.
- 런 시작 시각을 **서버 시계**로 찍어, 보고된 시각보다 실제 경과가 짧으면 거부합니다.

- 자유 플레이는 **시드를 서버가 발급**하므로 유리한 판을 고를 수 없습니다.

다만 **"불가능한 점수"를 막을 뿐 "사람이 아닌 것"은 막지 못합니다.**
판이 결정론적이라 완전 탐색으로 최적해를 구한 뒤 실제 시간만 흘려보내면 구분되지 않습니다.
한계는 [worker/README.md](worker/README.md)에 정리해 두었습니다.

### 이름

**순위 패널**에서 **순위표에 쓸 이름**을 적습니다(홈 화면 → 순위표, 또는 게임이 끝난 뒤
자동으로 열리는 화면). 이 기기에 저장되어 다음 판에도 같은 이름으로 등재됩니다.
비워 두면 서버가 지어 줍니다(`또렷한각도-300` 형태).

12자까지, 연속 공백은 한 칸으로, 제어문자와 링크는 거부합니다.
판정은 서버가 하므로 클라이언트를 우회해도 규칙은 같습니다.

### 개인정보

순위표에 공개되는 것은 **이름 · 랭킹 점수 · 레벨 · 제출 시각**뿐입니다.
실명·이메일을 요구하지 않으며, IP 는 평문으로 저장하지 않고 솔트를 섞은 해시만 남깁니다.
기기 식별자는 브라우저가 만든 임의 문자열로, 개인을 알아내는 값이 아닙니다.

`/api/board` 는 공개 조회이므로 **순위표는 누구나 볼 수 있습니다.**
이름을 직접 적는 만큼, 적은 이름이 그대로 공개된다는 점에 유의하세요.
표현 자체는 걸러내지 않습니다 — 필요하면 `worker/index.js` 의 `cleanName` 에
금지어를 추가하세요.

## 접근성

WCAG 2.2 기준으로 맞췄습니다.

- 전체 키보드 조작 (방향키 이동 · `Enter` 설치 · `Q`/`E` 회전 · `Space` 발사)
- 색에 의존하지 않는 구분 — 실패 빔은 점선, 시간 경고는 사선 패턴, 출구는 `EXIT` 글자
- 텍스트 대비 4.5:1 이상, 비텍스트 3:1 이상, 터치 타깃 44px 이상
- 일시정지(`P`), 연출 끄기(`F`), 소리 끄기(`M`), 스크린리더 상태 안내

## 구조

```
public/index.html   게임 (화면·입력·소리·연출)
public/core.js      결정론 코어 — 판 생성·시뮬레이션·점수·리플레이 검증
                    브라우저와 검증 서버가 같은 파일을 씁니다
worker/index.js     순위 API (Cloudflare Workers + D1)
worker/schema.sql   D1 스키마 (새로 만들 때)
worker/migrations/  이미 배포된 D1 에 반영할 변경
wrangler.toml       게임과 API를 한 주소에 함께 배포하는 설정
```

> **주의** — wrangler 4.x 는 Node.js 22 이상이 필요합니다.

## 개발

`public/index.html`을 브라우저로 바로 열면 게임은 그대로 동작합니다.
(`file://`에서는 순위 기능만 꺼집니다)

순위까지 시험하려면:

```bash
npx wrangler dev
```

배포 — **D1 마이그레이션을 먼저 적용해야 합니다** (안 하면 순위 기능이 죽습니다):

```bash
npx wrangler d1 execute mirror-rush --file=worker/migrations/002-client-id.sql --remote
```

```bash
npx wrangler deploy
```

자세한 배포·검증 내용은 [worker/README.md](worker/README.md),
버전별 변경 내역은 [CHANGELOG.md](CHANGELOG.md)를 보세요.
